## Codebase Patterns
- Frontend JS modules are in static/js/pages/ with corresponding exports via keysModule
- The keysModule object is exposed on window for HTML onclick handlers
- crypto.getRandomValues() is available in browser context for secure randomness
- Go build: `go build ./...` to verify backend compiles
