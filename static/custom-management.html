API Usage Examples

Copy these curl examples to test your proxy. Replace YOUR_API_KEY with your access key and YOUR_HOST with your server address.

OpenAI Compatible

Chat Completions (Recommended)

Use this format for OpenAI SDK compatibility. Works with any model through the unified endpoint.

curl -X POST "http://YOUR_HOST:8080/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello, how are you?"}
    ],
    "max_tokens": 1024,
    "temperature": 0.7,
    "stream": false
  }'
Streaming example: 
curl -X POST "http://YOUR_HOST:8080/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini-2.5-pro",
    "messages": [{"role": "user", "content": "Write a poem"}],
    "stream": true
  }'
OpenAI Legacy

Completions (Legacy)

Legacy completions endpoint for older applications. Uses prompt-based format instead of messages.

curl -X POST "http://YOUR_HOST:8080/v1/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini-2.5-flash",
    "prompt": "Write a short story about a robot:",
    "max_tokens": 512,
    "temperature": 0.8
  }'
Anthropic Native

Messages API

Native Anthropic format for Claude models. Uses x-api-key header and Anthropic's message structure.

curl -X POST "http://YOUR_HOST:8080/v1/messages" \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "system": "You are a helpful coding assistant.",
    "messages": [
      {"role": "user", "content": "Explain async/await in JavaScript"}
    ]
  }'
With streaming: 
curl -X POST "http://YOUR_HOST:8080/v1/messages" \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "stream": true,
    "messages": [{"role": "user", "content": "Hello Claude!"}]
  }'
Utility

List Available Models

Retrieve the list of all available models from the proxy.

curl "http://YOUR_HOST:8080/v1/models" \
  -H "Authorization: Bearer YOUR_API_KEY"

Tips

  • Model names: Use any model from the "Available Models" tab. The proxy routes to the correct provider automatically.
  • API Keys: Create access keys in the "API Keys" tab. Use them in the Authorization header.
  • Streaming: Add "stream": true for real-time token streaming responses.
  • Provider routing: You can prefix model names with provider (e.g., anthropic/claude-sonnet-4-20250514) for explicit routing.
